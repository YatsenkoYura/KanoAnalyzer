# KanoAnalyzer

Инструмент анализа пользовательских отзывов с применением NLP и ML.

## Запуск

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```

## Режимы работы

### Легкий режим
- Использует классические ML-алгоритмы (scikit-learn)
- Быстрый анализ без GPU

### Тяжелый режим
- GPU по возможности
- Трансформер-модели (LaBSE, Transformers)
- LangChain для обработки текстов
- Более точный анализ

## Использование
1. Загрузите файл с текстовых данных для анализа
2. Выберите режим (Легкий/Тяжелый)
2.1. Настройте по вкусу параметры
3. Получите классификацию и анализ
